# FXAutomaticTrading

## 概要
本リポジトリは、MetaTrader 5（MT5）上で動作するFX自動売買（EA）を扱います。  
自動売買とは、あらかじめ決めたルールに従って、売買の判断から注文・決済までをシステムが自動で行う仕組みです。

## 開発環境
- [Windows版 MetaTrader 5](https://www.metatrader5.com/ja)
- [MetaEditor 5](https://www.metatrader5.com/ja/automated-trading/metaeditor)

## 使用ファイル
- [FVG_Scalp_Turbo_v2.mq5](Experts/FVG_Scalp_Turbo_v2.mq5)

## 導入手順（マニュアル）
1. MT5をインストール
2. MetaEditorを開く
3. 新規ファイルを作成し、`Experts` 配下に配置
4. 作成したファイルにコードを追加
5. コンパイルし、エラーがなければMT5へ
6. MT5のストラテジーテスターを開き、バックテストを行う
7. 銘柄を選んでチャートを表示し、ナビゲータからEAファイルをチャートへドラッグ
8. MT5の設定で「アルゴリズム取引」が有効になっているか確認
9. チャート右上にファイル名と青色のマークが出ていたら完了

## 常時稼働について（重要）
EAは **MT5を起動している間のみ** 作動します。  
24時間稼働させたい場合は、VPS/サーバー環境の利用を推奨します。

### サーバー（例）
- [シンクラウドデスクトップ](https://shin-cloud-desktop.jp/)

サーバーとリモートデスクトップを接続し、そこでMT5をインストールして上記手順を行ってください。  
その後、自動売買が動いている状態で **MT5は開いたまま** リモートデスクトップを閉じてください。
