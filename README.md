# FXAutomaticTrading

## FX自動売買

### 開発環境  
- [Windows版 Meta Trading 5](https://www.metatrader5.com/ja)  
- [Meta Editor 5](https://www.metatrader5.com/ja/automated-trading/metaeditor)  

### サーバー
- [シンクラウドデスクトップ ](https://shin-cloud-desktop.jp/)

### 今回使用したファイル
[FVG_Scalp_Turbo_v2.mq5](Experts/FVG_Scalp_Turbo_v2.mq5)  


自動売買とは、あらかじめ決めたルールに従って、  
売買の判断から注文・決済までをシステムが自動で行う仕組みです。

## マニュアル
1. MT5をインストール
2. MetaEditorを開く
3. 新規ファイルを作り、Experts直下に移動
4. 作成したファイルにコードを追加
5. コンパイルし、エラーがなければMT5に移動
6. MT5のストラテジーテスターを開きバックテストを行う
7. 実際に動かすために銘柄からチャートを出して、ナビゲータから使用するファイルをチャートへドラッグ
8. MT5の設定からアルゴリズム取引の欄にチェックが入ってるか確認
9. チャート上の右上にファイル名と青色のマークが出ていたら完了です。
